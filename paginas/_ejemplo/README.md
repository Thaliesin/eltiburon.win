# Esta carpeta es una plantilla

`paginas/_ejemplo/` empieza por `_`, así que `scripts/build.mjs` la ignora
siempre: nunca se publica. Está aquí solo como referencia de cómo tiene
que quedar tu carpeta real.

No la copies a mano — usa `node scripts/nueva-pagina` o sigue
`docs/COMO-SOLICITAR-UNA-SUBIDA.md`, que hacen esto mismo sin que tengas
que acordarte de nada.
